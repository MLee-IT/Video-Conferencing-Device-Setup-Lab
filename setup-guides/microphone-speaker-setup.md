# Microphone and Speaker Setup

## Purpose

Provides instructions for connecting, configuring, and testing microphone and speaker devices used for video conferencing.

## Setup Steps

### 1. Connect the Devices

Connect the microphone and speakers to the computer or video conferencing system using the appropriate connections.

### 2. Verify Device Detection

Open the computer's sound settings and confirm that the microphone and speakers are recognized.

### 3. Comfigure the Microphone

Select the correct microphone as the input device.

Speak into the microphone and verify that the input level responds.

### 4. Configure the Speakers

Select the correct speakers as the output device.

Play a test sound and verify that audio can be heard clearly.

## 5. Configure the Video Conferencing Application

Open the video conferencing appliation.

Select the correct microphone and speakers in the application's audio settings.

### 6. Test the Audio

Start a test meeting and verify:

- Microphone input is working
- Selected output is working
- Audio is clear
- There is no unexpected feedback or echo

## Troubleshooting

If the microphone does not work, check:

- Cable or USB connection
- Microphone permissions
- Selected input device
- Microphone mute status
- Device detection
- Application audip settings

If the speakers do not work, check:

- Cable or USB connection
- Selected output device
- System volume
- Application volume
- Speaker mute status
- Device detection

## Final Verification

Confirm that the correct microphone and speakers are selected and that both input and output audio work properly before the meeting begins.
