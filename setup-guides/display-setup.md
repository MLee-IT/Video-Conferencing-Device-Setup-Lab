# Display Setup

## Purpose

Provides instructions for connecting, configuring, and testing a monitor or display used for video conferencing.

## Setup Steps

### 1. Connect the Display

Connect the monitor or conference room display to the computer or video conferencing system using HDMI or another supported video connection.

### 2. Power On the Display

Turn on the display and select the correct input source.

### 3. Verify Display Detection

Open the computer's display settings and confirm that the display is recognized.

### 4. Configure Display Settings

Select the appropriate display mode based on the conference room setup.

Common options include:

- Duplicate displays
- Extend displays
- Shpw presentation on the conference room display

### 5. Adjust Resolution

Select a supported display resolution and verify that the image appears correctly.

### 6. Test the Display

Confirm that:

- The display shows the correct image
- Text is readable
- The resolution is appropriate
- The correct input source is selected
- Meeting content can be displayed

## Troubleshooting

If the display does not work, check:

- Power connection
- HDMI or Video cable
- Display input source
- Display settings
- Supported resolution
- Device detection

## Final Verification

Confirm that the display is powered on, connected correctly, displaying the expected content, and ready for the video meeting.
