# Conference Room Setup

## Purpose

Provides a step-by-step guide for setting up a conference room for a video meeting.

## Equipment

- Video conferencing camera
- Microphone
- Speakers
- Monitor or display
- Computer or video conferencing system
- USB cables
- HDMI cable
- Power cables
- Network connection

## Setup Steps

### 1. Connect Power

Connect the computer or video conferencing system, display, camera, microphone, and speakers to power as required.

### 2. Connect the Display

Connect the computer or video conferencing system to the monitor or diplay using HDMI or another supported video connection.

### 3. Connect the Camera

Connect the conference camera to the computer or conferencing system using the appropriate USB or supported connection.

Position the camera so participants can be clearly seen.

### 4. Connect Audio Devices

Connect the microphone and speakers to the computer or conferencing system.

Make sure the microphone is positioned where participants can be heard clearly.

### 5. Verify Network Connectivity

Confirm that the computer or conferencing system has a working network connection.

### 6. Configure Video

Open the video conferencing application and select the correct camera.

Verify that the camera provides a clear video image.

### 7. Configure Audio

Select the correct microphone and speaker devices.

Test the microphone input and speaker output.

### 8. Test the Display

Confirm that the meeting content appears correctly on the conference room display.

### 9. Test a Meeting

Start a test meeting and verify:

- Camera functionality
- Microphone functionality
- Speaker functionality
- Display functionality
- Network connectivity

## Final Verification

Before the meeting begins, confirm that all equipment is powered on, connected, configured, and functioning properly.

## Troubleshooting

If a device does not work as expected, identify whether the issue is related to:

- Power
- Cable connections
- Device selection
- Drivers
- Network connectivity
- Application settings
- Hardware failure
