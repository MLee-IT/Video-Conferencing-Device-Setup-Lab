# Equipment Inventory

## Purpose

Documents the equipment used in the simulated video conferencing environment.

## Equipment

| Equipment | Purpose |
|---|---|
| Video Conferencing Camera | Captures video of meeting participants |
| Microphone | Captures participant audio |
| Speakers | Provides meeting audio |
| Monitor or Display | Displays meeting content and participants |
| Computer or Conferencing System | Runs the video conferencing application |
| USB Cables | Connect supported peripherals |
| HDMI Cable | Connects the computer or conferencing system to the display |
| Power Cables | Provides power to equipment |
| Network Connection | Provides connectivity for video conferencing |

## Equipment Verification

Each device should be checked for proper connection, power, detection, and functionality before a meeting.

## Documentation Notes

This inventory represents equipment used in the simulated IT lab environment. Specific manufacturers and models are not assigned because the project is intended to demonstrate general video conferencing setup and troubleshooting skills.
