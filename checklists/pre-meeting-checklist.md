# Pre-Meeting Checklist

## Purpose

Provides a quick checklist for verifying that a conference room is ready before a vdeo meeting begins.

## Equipment

- [ ] Camera is connected and positioned correctly
- [ ] Microphone is connected and working
- [ ] Speakers are connected and working
- [ ] Conference room display is powered on
- [ ] Computer or conferencing system is powered on
- [ ] Required cables are connectd securely

## Network

- [ ] Device is connected to the network
- [ ] Network connection is stable
- [ ] Connectivity test completed

## Video

- [ ] Correct camera is selected
- [ ] Camera preview displays correctly
- [ ] Camera angle is appropriate
- [ ] Video quality is acceptable

## Audio

- [ ] Correct microphone is selected
- [ ] Microphone input is working
- [ ] Correct speakers are selected
- [ ] Speaker output is working
- [ ] No unexpected echo or feedback

## Display

- [ ] Correct display input is selected
- [ ] Meeting content appears correctly
- [ ] Display resolution is appropriate

## Meeting Test

- [ ] Test meeting completed
- [ ] Audio tested
- [ ] Video tested
- [ ] Screen or presentation shared tested

## Final Verification

- [ ] All equipment is ready
- [ ] Room is ready for participants
- [ ] Any issues have been documented or escalated
