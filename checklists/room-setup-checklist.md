# Room Setup Checklist

## Purpose

Provides a checklist for setting up a conference room before configuring and testing video conferencing equipment.

## Power

- [ ] Conference room display is connected to power
- [ ] Computer or conferencing system is connected to power
- [ ] Camera is powered
- [ ] Microphone is powered
- [ ] Speakers are powered

## Connections

- [ ] Display cable is connected
- [ ] Camera cable is connected
- [ ] Microphone connection is secure
- [ ] Speaker connection is secure
- [ ] Network connection is established
- [ ] Required cables are secured and organized

## Equipment Placement

- [ ] Camera is positioned correctly
- [ ] Camera provides a clear view of participants
- [ ] Microphone is positioned appropriately
- [ ] Speakers are positioned correctly
- [ ] Display is visible to participants

## Device Configuration

- [ ] Camera is detected
- [ ] Microphone is detected
- [ ] Speakers are detected
- [ ] Display is detected
- [ ] Correct devices are selected in the conferencing application

## Testing

- [ ] Camera test completed
- [ ] Microphone test completed
- [ ] Speaker test completed
- [ ] Display test completed
- [ ] Network connectivity tested

## Final Verification

- [ ] Equipment is functionin properly
- [ ] Cables are organized
- [ ] Conference room is ready for use
- [ ] Any issues have been documented
