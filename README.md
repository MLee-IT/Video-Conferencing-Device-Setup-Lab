# Video-Conferencing-Device-Setup-Lab

## Overview

This project is a simulated IT lab demonstrating the setup, configuration, testing, and troubleshooting of video conferencing equipment used in conference rooms and workplace environments.

The lab focuses on practical hardware and software support tasks that an IT technician may perform when preparing a room for virtual meetings.

## Project Purpose

The purpose of this project is to demonstrate hands-on understanding of video conferencing device setup, peripheral configuration, connectivity, testing, and troubleshooting.

## Skills Demonstrated

- Video conferencing device setup
- Webcam and camera configuration
- Microphone and speaker configuration
- Monitor and display setup
- USB and HDMI connectivity
- Audio and video testing
- Network connectivity troubleshooting
- Microsoft Teams and Zoom meeting setup
- Hardware troubleshooting
- User support and documentation

## Setup Guides

The `setup-guides` folder contains documentation for configuring video conferencing equipment and related peripherals.

## Troubleshooting

The `troubleshooting` folder contains common video conferencing problems and recommended troubleshooting steps.

## Checklists

The `checklists` folder contains preparation and verification checklists for conference room setup.

## Documentation

The `documentation` folder contains supporting information about equipment, configuration, and the simulated lab environment.

## Lab Scenario

This project simulates an IT technician preparing a conference room for a virtual meeting.

The technician is responsible for connecting and configuring the equipment, testing audio and video functionality, verifying the display, checking connectivity, and resolving common issues before the meeting begins.

## Goal

The goal of this lab is to demonstrate practical IT support skills related to workplace video conferencing environments while documenting the setup and troubleshooting process clearly.
