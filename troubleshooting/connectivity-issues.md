# Connectivity Issues

## Problem

The video conferencing system or computer cannot connect to the network or has an unstable connection during a meeting.

## Troubleshooting Steps

### 1. Check the Network Connection

Verify that the computer or conferencing system is connected to the network.

### 2. Check the Network Cable

If using a wired connection, confirm that the Ethernet cable is securely connected.

### 3. Check Wi-Fi

If using Wi-Fi, confirm that the device is connected to the correct wireless network.

### 4. Check Network Status

Open the computer's network settings and verify that the connection is active.

### 5. Test Connectivity

Use a basic connectivity test such as:

```powershell
ping google.com
```

Review the results to determine whether the device can reach an external destination.

### 6. Restart the Network Connection

Disconnect and reconnect the network connection if appropriate.

### 7. Restart the Device

If connectivity problems continue, restart the computer or video conferencing system and test the connection again.

## Expected Result

The device should maintain a stable network connection suitable for video and audio communication.

## Escalation

If connectivity problems continue after troubleshooting, document the steps performed and escalate the issue to the appropriate network or IT support team.
