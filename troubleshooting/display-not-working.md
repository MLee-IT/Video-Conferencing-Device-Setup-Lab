# Display Not Working

## Problem

The conference room monitor or display is not showing an image from the computer or video conferencing system.

## Troubleshooting Steps

### 1. Check Power

Confirm that the display is powered on and connected to a working power source.

### 2. Check the Video Cable

Verify that the HDMI or other video cable is securely connected at both ends.

### 3. Check the Input Source

Use the display controls to select the correct input source, such as HDMI 1 or HDMI 2.

### 4. Check Display Settings

Open the computer's display settings and confirm that the external display is detected.

### 5. Check Display Mode

Verify that the display mode is configured correctly.

Try Duplicate or Extend if appropriate for the conference room setup.

### 6. Test the Cable and Port

If possible, try a known-working cable or another supported video port.

### 7. Restart the Equipment

Restart the computer or conferencing system and the display if necessary.

## Expected Results

The conference room display should show the computer's screen or meeting content.

## Escalation

If the display remains unavailable, document the troubleshooting steps and escalate the issue for further technical support.
